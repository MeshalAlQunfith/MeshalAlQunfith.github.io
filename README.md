# Meshal Al Qunfith — Portfolio Website

A responsive personal portfolio for business analysis and Power BI projects.

## Publish on GitHub Pages
1. Create a **public** repository named `MeshalAlQunfith.github.io` under the GitHub account `MeshalAlQunfith`.
2. Upload `index.html` to the repository root and commit.
3. Go to **Settings → Pages → Build and deployment**.
4. Choose **Deploy from a branch**, branch **main**, folder **/(root)**, and save.
5. Wait for deployment. The portfolio URL will be `https://MeshalAlQunfith.github.io/`.

If your username differs, replace the links and repository name accordingly.

The dashboard illustration is decorative; actual project files live in the linked ServiceFlow repository.
